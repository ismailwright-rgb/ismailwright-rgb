# wheels through cp314; onnxruntime is the one with the higher macOS floor.

# piper-tts (text -> speech, speaking):
# Licensed GPL-3.0-or-later. This codebase is proprietary - deliberately
# NOT imported anywhere in core/ or api/ (see core/speak.py's docstring).
# It runs as its own separate local process (`python3 -m
# piper.http_server`), talked to only over localhost HTTP, the same
# relationship this app already has with Ollama. That boundary is the
# reason this dependency is safe to install on a dev machine to *run* the
# voice server, without it ever becoming part of the proprietary Python
# process this app ships. Still needs real legal review before this goes
# to any paying client - this comment states the boundary chosen, not a
# legal conclusion. Verified against PyPI directly: piper-tts 1.6.1 ships
# real macosx_11_0_arm64 and macosx_10_9_x86_64 wheels.
#
# The [http] extra is required, not optional - piper.http_server (what
# actually runs the voice service) imports flask, but the base piper-tts
# package does not depend on it. Confirmed directly against PyPI's own
# requires_dist for this version, after hitting the bare `piper-tts`
# install missing it live: flask<4,>=3 is declared only under
# `extra == "http"`.
piper-tts[http]==1.6.1
